# TCC-Inadimplencia-de-Credito

Para garantir a reprodutibilidade deste projeto e evitar conflitos de versão, utilizamos um ambiente virtual. Siga os passos abaixo:

**1. Clone este repositório:**
`git clone https://github.com/Heimrath/TCC-Inadimplencia-de-Credito.git`

**2. Crie um ambiente virtual (venv):**
`python -m venv venv`

**3. Ative o ambiente virtual:**
* No Windows: `.\venv\Scripts\activate`
* No Mac/Linux: `source venv/bin/activate`

**4. Instale as dependências exigidas:**
`pip install -r requirements.txt`
